# Fleasion Mobile Companion — v0.4.0

A friendly, phone-first Progressive Web App for organizing local profiles and replacement-rule notes, with JSON import/export. This is an independent companion prototype, not an official Fleasion or Roblox app.

## What's new in v0.4.0
- A simpler welcome screen and a three-step getting-started guide.
- Clearer labels for profiles, rules, backups and tools.
- Cleaner navigation with compact section tabs.
- Refreshed dark and light themes with more consistent cards and spacing.
- Existing profile, rule, import/export, validation and local-storage features remain available.

## Install on Android
1. Open the hosted app over HTTPS in Chrome.
2. Refresh the page, or close and reopen the installed app so it loads the updated files.
3. If the old design remains, clear the site's cached files in Chrome and reload.
4. Use Chrome's menu and choose **Install app** or **Add to Home screen**.

## Data and compatibility
Profiles are stored in this browser's local storage. Use **Export backup** to keep a portable JSON copy and **Import file** to add a profile on another device. The export format is a companion format and is not guaranteed to match every Fleasion release or configuration schema.

## Important limitations
This app edits and exports local data only. It does not intercept Roblox traffic, modify a running Roblox client, bypass platform protections, or provide desktop-only proxy, TLS certificate, process-launching, OpenGL or audio features. A rule appearing in this companion does not mean it is applied in Roblox.
